# 核心术语与检索入口

- **FDE**：把客户问题推进到生产、并将现场发现回流组织的复合角色（02、05）。
- **FDPM**：负责需求和客户组织牵引的前线产品角色（05）。
- **Echo**：问题定义、行业洞察和通用资产建设能力，不必然是固定部门（02）。
- **Delta**：现场验证、集成和交付能力，不必然是固定部门（02）。
- **双向蒸馏**：现场信息形成资产，资产反向降低后续交付成本（02）。
- **本体层**：对行业实体、关系、规则和行动的结构化表达（03–04）。
- **Skill**：封装一种可执行任务的通用能力（04）。
- **连接器**：对接业务系统的可维护接口（04）。
- **核心路径 / 扩展点**：共同流程与按客户激活的可选能力（09）。
- **客户 Skill**：访问某客户数据的具体能力，使用权和产权需单独约定（09）。
- **L0–L4**：报告用于描述 Demo 走向生产与规模化的阶段框架（05）。
- **原厂—伙伴—客户**：样板、复制、自助的责任转移结构（06）。
- **边际交付成本**：每增加一个同类客户所需额外交付与支持投入（07、09）。
- **招聘样本**：自采 273 条有效海外职位与其他平台快照；口径不能合并（附录）。
- **虚构 ERP 案例**：第9章的教学情境，所有数字均为估算（09）。
